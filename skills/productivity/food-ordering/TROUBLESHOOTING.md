# 故障速查

运行中遇到问题？先来这里查。

> ⚠️ **注意**：以下内容基于预期问题整理，暂无日志证据支持。实际遇到问题请记录到 LOG.md。

## ADB 设备断开
**现象**: `adb devices` 空列表  
**解法**: 重新插拔 USB → 解锁手机 → 点「允许 USB 调试」  
**状态**: 待验证

## 输入框不吃字
**现象**: Type 后输入框空白  
**解法**: 切 ADB Keyboard: `adb shell ime set com.android.adbkeyboard/.AdbIME`  
**状态**: 待验证

## 手机锁屏导致中断
**现象**: 中途黑屏，ADB 断开  
**解法**: 设置 30 分钟息屏: `adb shell settings put system screen_off_timeout 1800000`  
**状态**: 待验证

## 起送金额不够
**现象**: 提示「再买¥X起送」  
**解法**: 加最便宜小食，别凑贵饮料  
**状态**: 待验证

## 优惠券没减
**现象**: 结算价 = 原价  
**解法**: 检查是否满足满减门槛，手动勾选红包  
**状态**: 待验证

## 地址不在配送范围
**现象**: 提示不在配送范围内  
**解法**: 换更近的楼栋，或选距离近的店（筛选「30分钟内」）  
**状态**: 待验证
